Study of HTML Image Tag

Introduction

The HTML <img> tag is used to display images on web pages. Images make websites visually attractive and informative.

Example of Image Tag

The flower image below is displayed using the HTML <img> tag.

Attributes Used

  • src - Specifies image URL
  • alt - Alternate text
  • width - Sets image width
  • height - Sets image height

Conclusion

The image tag is essential in HTML for adding visual elements and improving website appearance.
