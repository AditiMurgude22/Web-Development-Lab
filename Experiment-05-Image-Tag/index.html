Study of HTML Image Tag

Introduction

The HTML <img> tag is used to display images on a web page. Images make web pages more attractive and help users understand content visually.

Example of Image Tag

The flower image below is displayed using the HTML <img> tag.


Attributes Used in Image Tag

  • src - Specifies the image path or URL
  • alt - Displays alternate text if image is not loaded
  • width - Sets image width
  • height - Sets image height

Conclusion

The image tag is an important HTML element used to add visual content to websites and improve user experience.
