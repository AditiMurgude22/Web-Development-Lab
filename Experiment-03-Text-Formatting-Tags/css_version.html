Study of Text Formatting Tags in HTML

Name: Aditi Murgude Roll No: 100

Introduction

HTML provides various text formatting tags to improve the appearance and readability of web content. These tags help highlight important text.

Examples of Text Formatting Tags

Bold text using <b> tag

Strong text using <strong> tag

Italic text using <i> tag

Emphasized text using <em> tag

Underlined text using <u> tag

Marked text using <mark> tag

Small text using <small> tag

Deleted text using <del> tag

Inserted text using <ins> tag

Subscript text: H2O using <sub> tag

Superscript text: X2 using <sup> tag

Conclusion

Text formatting tags are important in HTML for structuring and styling content effectively. They improve readability and presentation.
