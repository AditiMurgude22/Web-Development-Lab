Welcome to My Static Web Page

Introduction

This is a simple static web page created using basic HTML tags. A static web page displays fixed content and does not change unless manually updated by the developer.

Static web pages are easy to create and are mainly used for displaying information such as personal portfolios, project pages, and company details.

HTML Tags Used

  • Heading tags (h1, h2, h3)
  • Paragraph tag (p)
  • List tags (ul, li)
  • Horizontal line tag (hr)
  • Line break tag (br)
  • Center tag (center)

Advantages of Static Web Pages

  1. Easy to create and maintain
  2. Fast loading speed
  3. Secure and reliable
  4. Best for small websites

Conclusion

HTML is the foundation of web development and is used to structure content on the web. Static web pages are the first step in learning website development.
