Introduction

This is a simple static web page created using HTML tags. Static web pages contain fixed information and are mainly used for simple websites and web design practice.

HTML Tags Used

  • Heading tags (h1, h2, h3)
  • Paragraph tag (p)
  • List tags (ul, ol, li)
  • Division tag (div)
  • Break tag (br)

Advantages of Static Web Pages

  1. Easy to create
  2. Fast loading speed
  3. Simple maintenance
  4. Secure and reliable

Conclusion

HTML is the foundation of web development and helps in building structured web pages. Static websites are the starting point for beginners.
